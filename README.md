# Chat Realtime

Projeto desenvolvido com foco em aprender como funciona um **chat em tempo real**, utilizando **Java**, **Spring Boot** e **WebSocket**.  

Além da implementação do backend, foi criado um **HTML simples** com **JavaScript** para testar a comunicação em tempo real com o servidor.

## 🚀 Tecnologias Utilizadas

- **Java**: Linguagem principal do projeto.
- **Spring Boot**: Framework para construção da API.
- **WebSocket**: Comunicação em tempo real entre clientes e servidor.
- **JavaScript (Frontend)**: Para conectar o chat com o backend.
- **HTML + CSS**: Interface simples para visualizar o chat funcionando.

## ✨ Funcionalidades

- **Envio e recebimento de mensagens em tempo real**.
- **Conexão WebSocket** para comunicação eficiente entre os usuários.
- **Frontend simples** para testar o funcionamento do chat.
- **Integração entre frontend e backend usando JavaScript**.
